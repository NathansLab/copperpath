# 0027 CI: KiCad DRC gate and nightly benchmark with history on GitHub Pages

GitHub: https://github.com/NathansLab/copperpath/issues/14
Status: open (infrastructure)

## Boards
`bench/boards/` with 5-8 boards from free sources only. Record the license and source URL of each
board in `bench/boards/LICENSES.md`.
- KiCad demo projects (check the license per demo).
- PCBench boards with a permissive license.
- 1-2 synthetic boards generated by a script (`scripts/make_synth.py`).
  - One large: ~6 layers, 300 footprints, 400 nets, 0.05 mm grid region 200 x 120 mm.
  - One dense: two-layer bus crossing (see #7).
  - No project data of any kind.

## 1. DRC gate in PR CI (`kicad/kicad:10.0` container or the KiCad PPA)
- Route 2-3 small boards, then `kicad-cli pcb drc --format json --schematic-parity off`.
- The job fails on any new `clearance`, `shorting_items`, `hole_clearance`, `track_width` or
  `annular_width` error, or on more opens than `bench/baseline.json`.
- Under 10 min in total.

## 2. `bench.yml` (nightly cron + workflow_dispatch, under 20 min)
- All bench boards with `--threads 4 --drc --json`.
- Metrics per board: time, ok, opens, vias, length, new DRC errors. Output as one JSON file.
- History on gh-pages (e.g. `benchmark-action/github-action-benchmark`).
- More than 20 % slower or new opens → open an issue as github-actions[bot].
  The workbench ignores bot issues; Nathan triages them.
- README note: runtimes on shared runners scatter (±20 %).

## 3. GitHub Pages
Benchmark page with history curves and before/after PNGs of each board (copper layers + Edge.Cuts
via `kicad-cli pcb export svg` → PNG). Link it from the README.

## Acceptance
A PR that removes a clearance check turns the DRC gate red. The nightly run publishes the page.
